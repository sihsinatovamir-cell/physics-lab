# Инженерная лаборатория

Статический учебный сайт: виртуальные опыты по механике (К1) и визуализатор
численных методов (К2). Всё считается в браузере, серверной части нет.

**Живая версия:** https://sihsinatovamir-cell.github.io/physics-lab/

- К1 — математический маятник, пружинный маятник, наклонная плоскость,
  закон Архимеда, вязкость жидкости (метод Стокса). В каждом опыте — серия
  измерений с приборными погрешностями, расчёт по Стьюденту, МНК и экспорт
  отчёта в .docx прямо в браузере.
- К2 — решение уравнений (дихотомия, Ньютон, хорды, простая итерация),
  дифференциальные уравнения (Эйлер, Эйлер–Кромер, РК4), метод Монте-Карло,
  численное дифференцирование и интегрирование, ряды Тейлора и интерполяция.

Собрано на Vite + TypeScript, интерфейс на русском, есть тёмная тема и
адаптив под телефон. В консоли браузера доступна команда `ilabSelfTest()` —
51 встроенная проверка численных алгоритмов.

Репозиторий содержит только собранный сайт (папка `dist` проекта).
